도구가 하는 일
• 잘림 탐지: answer가 8자 이하인 문제 중, text나 해설에 더 긴 명사구가 있으면 의심으로 표시
• 후보 추출: 정식 작품명 후보를 자동 발견 (예: answer "술집" → 후보 "폴리 베르제르의 술집")
• 사람 결정: 각 후보를 보고 Yes/No 선택. 직접 입력도 가능
• 자동 변환: 결정된 title 기준으로 answer/initials 자동 계산
• 구조 변환: display 필드 → title로 옮김. boxes 필드 폐기
• 문제 삭제: 출제 의도가 어긋난 문제는 통째로 삭제 가능 (재출제는 미래에)

4가지 결정 자세
1. 후보 클릭 — 잘림 발견. 후보가 정식 명칭
2. 직접 입력 — 후보가 부정확. 정식 명칭 직접 박기
3. 그대로 두기 — 잘림 아님. 짧은 정답이 정상 (예: 뫼르소, 거울)
4. 문제 삭제 — 질문 의도와 답이 어긋난 함정 문제 (예: "수식어를 묻는 질문")
